# イベント開催欲求診断

「なぜイベントをやりたいのか」を、12の場面質問から4タイプに分類する静的Web診断です。

## 4タイプの分析

4タイプの違いは、イベントを始めるときの「主語（エネルギーの中心）」として整理しています。

| タイプ | 主語 | 中心欲求 | イベントの役割 |
| --- | --- | --- | --- |
| つよびおたく | 愛する対象 | 魅力の伝播・発見の共有 | 未知の魅力との入口 |
| 無重力 | 起きる体験 | 新奇性・即興・実験 | 面白い偶然を起こす装置 |
| ナポレオン | 仲間と課題 | 連帯・共感・問題意識の共有 | 同志が出会う旗印 |
| 消臭力 | 自分自身 | 自己表現・影響・世界観の実現 | 個の美学を体験にする舞台 |

人は通常、複数の動機を持っています。そのため結果では、最多回答を主タイプ、次点を副タイプとして表示し、4タイプすべての比率も可視化します。同点時は安定した表示のため固定順で主タイプを決めますが、「ハイブリッド型」と明示します。

## 診断設計

- 12問・各4択
- 各選択肢が4タイプのいずれかに1点
- 抽象的な自己評価ではなく、企画・準備・当日・終了後の具体場面を質問
- 結果の“当てる感”だけでなく、タイプ別のイベントづくりのヒントを提供
- 診断結果を1080×1350pxのPNG画像にまとめ、写真フォルダや写真アプリへ保存
- 画像共有対応端末では、シェア時にも診断結果のPNG画像を添付
- 心理学的な性格検査ではなく、現在の開催動機を言語化するためのツール

## ローカルで確認

ビルドは不要です。

```bash
python3 -m http.server 4173
```

ブラウザで <http://localhost:4173> を開いてください。

## 公開

GitHub Pages で公開する場合は、リポジトリの `Settings` → `Pages` から、`Deploy from a branch`、`main`、`/(root)` を選択します。

## 構成

- `index.html` — 画面構造・メタ情報
- `styles.css` — レスポンシブデザイン
- `app.js` — 質問、採点、結果表示、シェア機能
